# Proton FC Kuningan — Fan-Made Website Concept

A fan-made multi-page website concept for Proton FC Kuningan, created as a front-end development portfolio project.

## About

This project is a multi-page football club website concept inspired by Proton FC Kuningan.

The website is designed to present club information, team information, competition details, match-related content, and the latest news through a modern and responsive interface.

The project focuses on building a structured football club website experience using fundamental front-end technologies without relying on an external JavaScript framework.

## Why I Built This

I built this project to combine my interest in football with my interest in front-end development.

I wanted to explore how a professional-style football club website could be structured and presented through a multi-page web interface.

Through this project, I practiced creating reusable page structures, navigation between multiple HTML pages, responsive layouts, content organization, image handling, and building a consistent visual identity across different sections of a website.
